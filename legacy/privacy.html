Privacy Policy

Last updated July 29, 2026

Beta notice: Scholia is currently in early testing and does not yet have user accounts or subscriptions. This policy describes the app's current, account-free design. It will be revised — and testers/users notified — before any account-based or paid features launch.

Overview

Scholia is an iOS app that helps readers of physical books get spoiler-free answers about the book they're holding. This policy explains what information the app and its supporting services handle, why, and for how long. Scholia is built around a simple principle: collect as little as possible, and never store the words scanned from a reader's book.

Information Scholia Collects

Scholia does not require an account, name, or email address to use the app. The information it processes falls into these categories:

  • Anonymous device identifier. On first launch, the app generates a random identifier stored only on the device. It is sent with each request solely to enforce a daily free-question limit and is never linked to a name, email, or Apple ID.
  • Book information. The title and author of books a reader adds to their library are sent to Scholia's server so it can retrieve chapter information and answer questions about that book.
  • Scanned page text. When a reader photographs a page, the text is recognized on-device using Apple's built-in text recognition (Vision framework) and is never uploaded as an image. The recognized text is sent to Scholia's server only to determine reading position and answer the reader's question in that moment. It is not stored after the request completes.
  • Chat messages. Questions typed into the chat, and the AI's answers, are sent to Scholia's server to generate a response. They are not stored server-side; the ongoing conversation lives only in the app on the reader's device.
  • Optional feedback. If a reader taps a thumbs-up or thumbs-down on an answer, that rating along with the associated question and answer text is stored anonymously (tied only to the device identifier, never a name) for up to 30 days to help improve answer quality, then automatically deleted.
  • Book search queries. Titles or authors typed while searching for a book are sent to Google Books and Open Library to return search results.

How Information Is Used

Information described above is used only to operate Scholia's core features: finding a reader's position in a book, answering questions without revealing spoilers, and searching for books to add to a library. Scholia does not sell information, use it for advertising, or build profiles of readers across sessions beyond the anonymous daily rate limit.

Third-Party Services

Scholia's server relies on the following services to function:

  • Anthropic (Claude models). Book titles, scanned page text, and chat messages are sent to Anthropic's API to generate answers. This data is processed by Anthropic in accordance with its own privacy policy and commercial API terms.
  • Google Books API and Open Library. Search queries (book title or author text typed by the reader) are sent to these services to return book search results.
  • Cloudflare Workers & KV. Scholia's server logic and the rate-limit/feedback storage described above run on Cloudflare's infrastructure.

These providers may process requests in accordance with their own privacy policies.

What Stays On the Device

A reader's library, reading position, and full chat history are stored locally on their iPhone using Apple's on-device storage (SwiftData) and are not backed up to any Scholia server. Uninstalling the app removes this data.

Data Retention

Scholia's server does not persist book titles, scanned page text, or chat content after a request is served. Anonymous feedback ratings are retained for at most 30 days. Rate-limit counters are retained for at most 48 hours.

Children's Privacy

Scholia is not directed at children under 13 and does not knowingly collect information from them.

Changes to This Policy

This policy may be updated as Scholia's features evolve. Material changes will be reflected here with an updated date at the top of this page.
